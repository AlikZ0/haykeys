# Установка HayKeys без собственного Mac

Нужны Ubuntu с USB-портом, iPhone, Wi-Fi, аккаунты GitHub и Apple Account. Проект собирает macOS-сервер GitHub Actions. Затем SideStore подписывает IPA вашим аккаунтом и устанавливает его. Локально Xcode на Ubuntu не запускается.

Этот путь подготовлен по документации GitHub и SideStore, но весь процесс с этим проектом ещё не выполнен: облачная сборка и установка на iPhone пока не проверены.

## 1. Соберите IPA на GitHub

1. Распакуйте архив. Рабочая папка называется `HayKeys`.
2. На GitHub создайте репозиторий, например `haykeys`. Для бесплатных стандартных runners выберите **Public**: исходники станут общедоступными. Можно включить создание README при создании репозитория.
3. Нажмите **Add file → Upload files** и загрузите **содержимое** папки `HayKeys`. В корне репозитория должны оказаться `App`, `Core`, `Keyboard`, `scripts`, `Tests`, `Config`, `HayKeys.xcodeproj` и остальные файлы. Загружать только ZIP не нужно: GitHub его не распакует.
4. В репозитории должен быть файл **`.github/workflows/build-ipa.yml`** из архива. Если он не попал в загрузку, нажмите **Add file → Create new file**, задайте этот путь и вставьте содержимое одноимённого файла из проекта. Сохраните в основной ветке.
5. Откройте **Actions → Build HayKeys IPA → Run workflow**. Если GitHub попросит включить Actions, включите их. В ветке `main` сборка также запускается после загрузки файлов автоматически.
6. Дождитесь зелёного статуса. Workflow сначала проверяет логику клавиатуры, затем собирает приложение и расширение для реального iPhone.
7. Внизу страницы запуска, в разделе **Artifacts**, скачайте **HayKeys-unsigned-IPA**. Распакуйте загруженный ZIP: внутри будет **HayKeys-unsigned.ipa**.

Для GitHub Actions не нужны пароль Apple Account, сертификаты или платный аккаунт Apple Developer. Workflow выполняет сборку без подписи. Для публичного репозитория со стандартным runner GitHub не взимает плату за время сборки. Артефакт хранится 3 дня; в проекте не используются платные larger runners.

Если сборка красная, откройте упавший шаг. IPA появится только после успешной сборки. Не продолжайте установку с другим случайным IPA. В этом случае нужен фактический текст ошибки GitHub Actions.

## 2. Подготовьте Ubuntu и SideStore

1. Установите поддержку подключения iPhone:

```bash
sudo apt update
sudo apt install usbmuxd
```

2. На <https://iloader.app/> выберите **Linux (x86_64) → Ubuntu/Debian (.deb)**. После скачивания откройте терминал в папке с файлом и выполните:

```bash
sudo apt install ./iloader-linux-amd64.deb
```

3. На iPhone установите бесплатный [LocalDevVPN](https://apps.apple.com/app/localdevvpn/id6755608044). Подключитесь к Wi-Fi. Подключите телефон кабелем к Ubuntu, разблокируйте его и подтвердите доверие компьютеру.
4. Запустите **iloader**, войдите в Apple Account, выберите телефон и нажмите **Install SideStore (Stable)**.

Пароль Apple Account вводится в инструменты установки, а не в GitHub. Файлы сопряжения телефона и сертификаты в публичный репозиторий не загружайте.

Официальная инструкция подготовки Linux: <https://docs.sidestore.io/docs/installation/prerequisites>.

## 3. Завершите настройку SideStore на iPhone

1. Откройте **Настройки → Основные → VPN и управление устройством**, выберите профиль своего Apple Account и подтвердите доверие. На новых iOS система может показать **«Разрешить и перезагрузить»**; подтвердите и введите код телефона.
2. Включите **Настройки → Конфиденциальность и безопасность → Режим разработчика**. После перезагрузки подтвердите включение.
3. В **LocalDevVPN** нажмите **Connect**.
4. Откройте **SideStore** и войдите в тот же Apple Account, который использовали в iloader.
5. В **My Apps** нажмите счётчик дней около SideStore, чтобы проверить продление его подписи.

Точные шаги по версиям iOS: <https://docs.sidestore.io/docs/installation/install>.

## 4. Установите HayKeys

1. Сохраните **HayKeys-unsigned.ipa** в приложение **«Файлы»** на iPhone. Например, откройте GitHub Actions в Safari, войдите в свой GitHub и скачайте Artifact прямо на телефоне; ZIP можно распаковать нажатием в «Файлах».
2. С подключёнными Wi-Fi и LocalDevVPN откройте **SideStore → My Apps → +**, выберите IPA и дождитесь подписания и установки.
3. Если установщик предложит удалить расширения приложения, **оставьте HayKeysKeyboard.appex**. В нём находится клавиатура; установка только основного приложения не даст возможности печатать в других приложениях.
4. Откройте HayKeys. Затем перейдите в **Настройки → Основные → Клавиатура → Клавиатуры → Новые клавиатуры** и добавьте **HayKeys Armenian**. Полный доступ не нужен.
5. Откройте «Заметки», нажмите текстовое поле, удерживайте **🌐** и выберите **HayKeys Armenian**.

Неподписанный IPA сам по себе не устанавливается нажатием в «Файлах». Подпись создаёт SideStore во время установки. Внешний вид и названия элементов SideStore могут отличаться между версиями.

## 5. Продлевайте подпись до истечения 7 дней

У бесплатного аккаунта остаётся срок подписи **7 дней**. До его истечения включите Wi-Fi и LocalDevVPN, откройте SideStore и обновите **HayKeys и сам SideStore** в My Apps. Повторная облачная сборка для обычного продления не нужна. Если подпись SideStore уже истекла, может потребоваться повторная установка через iloader с Ubuntu.

Лимиты бесплатного аккаунта: до 3 активных установленных таким способом приложений, включая SideStore, и до 10 App IDs за 7 дней. Расширения требуют App IDs. Детали: <https://docs.sidestore.io/docs/faq>.

## Если достаточно готовой клавиатуры

В армянском App Store есть бесплатная [Armenian Keyboard+](https://apps.apple.com/am/app/armenian-keyboard/id6753932933) с Eastern и Western Armenian. Она не требует Mac и еженедельной переподписи через SideStore. Точное совпадение её текущей раскладки со скриншотом не подтверждено.

Установите приложение, затем добавьте его в **Настройки → Основные → Клавиатура → Клавиатуры → Новые клавиатуры** и выберите через 🌐. По описанию разработчика, полный доступ не требуется.
